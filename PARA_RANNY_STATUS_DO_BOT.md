### 3. 📝 LEMBRETES INTELIGENTES

#### Criar Lembretes
**Como usar:**
```
Você: me lembra amanhã às 14h de ligar pro contador
Bot: ✅ Lembrete criado!
     📅 20/01 às 14:00
     📝 ligar pro contador
```

**Entende português natural:**
- "amanhã" → dia seguinte
- "segunda", "terça" → próximo dia da semana
- "dia 15" → dia 15 do mês
- "daqui 3 dias" → 3 dias a partir de hoje
- "daqui 5 minutos" → 5 minutos a partir de agora

#### Lembretes Recorrentes
**Como usar:**
```
Você: todo dia 7 lembra do FGTS
Bot: ✅ Lembrete criado!
     📅 07/02 às 09:00
     📝 FGTS
     🔄 Lembrete mensal
```

**Tipos de recorrência:**
- "todo dia" → diário
- "toda semana" / "toda segunda" → semanal
- "todo mês" / "todo dia 7" → mensal

#### Gerenciar Lembretes
```
Você: quais meus lembretes?
Bot: [lista todos os lembretes ativos]

Você: cancela lembrete do FGTS
Bot: ✅ Lembrete cancelado: FGTS
```
