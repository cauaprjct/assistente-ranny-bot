┌─────────────────────────────────────────────────────────────────────────────┐
│ PASSO 1: CRIAR BANCO POSTGRESQL                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. Acesse: https://dashboard.render.com/                                  │
│  2. Clique: "New +" → "PostgreSQL"                                         │
│  3. Preencha:                                                               │
│     • Name: assistente-ranny-db                                            │
│     • Database: assistente_ranny                                           │
│     • Region: Oregon (US West)                                             │
│     • Plan: Free                                                            │
│  4. Clique: "Create Database"                                              │
│  5. Aguarde: ~2 minutos                                                     │
│                                                                             │
│  ✅ Quando aparecer "Available", está pronto!                              │
│                                                                             │

┌─────────────────────────────────────────────────────────────────────────────┐
│ PASSO 2: COPIAR DATABASE_URL                                               │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. No banco criado, clique: "Info"                                        │
│  2. Procure: "Internal Database URL"                                       │
│  3. Clique no ícone de copiar (📋)                                         │
│                                                                             │
│  Exemplo da URL:                                                            │
│  postgres://user:pass@dpg-xxxxx-a.oregon-postgres.render.com/assistente... │
│                                                                             │
│  ⚠️ IMPORTANTE: Use "Internal", não "External"!                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────┐
│ PASSO 3: ADICIONAR VARIÁVEL NO WEB SERVICE                                 │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  1. Volte ao Dashboard                                                      │
│  2. Clique no seu Web Service (onde o bot está)                            │
│  3. Clique: "Environment"                                                   │
│  4. Clique: "Add Environment Variable"                                     │
│  5. Preencha:                                                               │
│     • Key: DATABASE_URL                                                     │
│     • Value: (cole a URL copiada)                                          │
│  6. Clique: "Save Changes"                                                  │
│                                                                             │
│  ⚠️ Isso vai reiniciar o serviço automaticamente!                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

================================================================================
❌ PROBLEMAS COMUNS
================================================================================

Problema: "DATABASE_URL não configurada"
Solução: Verifique se adicionou a variável no Web Service (Passo 3)

Problema: "Relatório não encontrado"
Solução: O arquivo relatorio_upload_backup.json deve estar na raiz do projeto

Problema: Busca retorna "Não encontrei documentos"
Solução: Verifique se a migração foi concluída nos logs (Passo 4)

Problema: Bot não responde
Solução: Verifique se o bot iniciou nos logs: "🤖 Bot iniciado com sucesso!"
