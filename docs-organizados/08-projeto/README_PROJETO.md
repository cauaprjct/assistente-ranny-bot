## 🚀 Quick Start

### Usar o Bot (Ranny)

1. Abra o Telegram
2. Entre no grupo "Documentos Ranny"
3. Vá no Tópico "Chat"
4. Converse: "Oi!"

**Leia:** `GUIA_PARA_RANNY.md`

### Rodar Localmente (Dev)

```bash
cd assistente-ranny
python bot.py
```

### Deploy no Railway

1. Conecte repositório GitHub
2. Configure variáveis de ambiente
3. Deploy automático

**Leia:** `PROXIMOS_PASSOS.md`
