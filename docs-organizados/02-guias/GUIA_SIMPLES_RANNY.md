- ✅ Vai iniciar automaticamente quando ligar o PC
- ✅ Roda invisível em segundo plano
- ✅ Envia arquivos automaticamente pro Telegram

## 🎯 O que a Ranny precisa saber:

### **NADA!** 😊

O monitor já está configurado para iniciar sozinho. Ela só precisa:

1. **Salvar arquivos normalmente** (Word, Excel, PDF)
2. **Os arquivos aparecem automaticamente no Telegram**

---

## 🔧 Se precisar fazer algo:

### **Ver se está funcionando:**
```
Clique duas vezes em: status_monitor.bat
```

### **Parar o monitor:**
```
Clique duas vezes em: parar_monitor.bat
```

### **Iniciar o monitor:**
```
Clique duas vezes em: iniciar_monitor.bat
```

### **Ver o que foi enviado:**
```
Clique duas vezes em: ver_log.bat
```

---

## 🚨 Se der problema:

1. Clique duas vezes em: `status_monitor.bat`
2. Se mostrar "PARADO", clique em: `iniciar_monitor.bat`
3. Pronto!

---

- **Word (.docx)** → Tópico Empresa
