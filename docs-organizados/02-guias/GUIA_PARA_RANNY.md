### Como Funciona:

1. **Envie qualquer arquivo** (PDF, foto, Excel, Word) no **Tópico Chat**
2. O bot **analisa automaticamente** com IA
3. Ele **classifica** e **move** para o tópico correto
4. Te **confirma** onde guardou
