## 🆘 PROBLEMAS COMUNS

### Bot não responde
- Verifique se está no grupo correto
- Tente `/start` novamente
- Aguarde alguns segundos

### Não encontrou documento
- Tente palavras-chave diferentes
- Use "lista todos" para ver tudo
- Verifique ortografia

### Lembrete não disparou
- Verifique se criou corretamente
- Use "quais meus lembretes?"
- Horário pode ter passado

### Relatório não abre
- Link expira em 24h
- Gere novo: "mostra gráfico da semana"
- Verifique conexão internet
