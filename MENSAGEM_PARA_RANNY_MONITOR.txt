O QUE MUDOU?
------------

Inicialmente eu tinha implementado uma sincronização automática pelo OneDrive 
para enviar seus arquivos para o Telegram. Mas isso ia precisar de DINHEIRO 
(assinatura do OneDrive).

Então mudei de ideia e fiz uma solução MUITO MAIS SIMPLES E DE GRAÇA!


A NOVA SOLUÇÃO
--------------

Criei um SCRIPT que roda no seu computador e envia automaticamente os arquivos 
novos ou modificados para o Telegram.

Como funciona?

  1. Você salva um arquivo no Desktop ou Documentos
  2. O script detecta automaticamente
  3. Envia para o Telegram no tópico "Arquivos PC (Local)"
  4. Pronto! Você pode acessar de qualquer lugar pelo celular

Que tipos de arquivo?

  - Excel (.xlsx, .xls)
  - Word (.docx, .doc)  
  - PDF (.pdf)


O QUE VOCÊ PRECISA FAZER?
--------------------------

É MUITO SIMPLES! Só 1 passo:

  1. Execute o instalador (eu vou fazer isso com você)
     - Vou executar: python instalar_monitor_simples.py
     - Vai aparecer umas mensagens
     - Aperte ENTER quando pedir
     - Quando perguntar se quer testar, digite S e aperte Enter
     - Pronto!

E depois?

  NADA!

O script vai:
  - Iniciar automaticamente quando você ligar o computador
  - Rodar invisível (você nem vai ver)
  - Enviar seus arquivos automaticamente
  - Não enviar duplicatas

Você não precisa fazer mais nada, é tudo automático!


COMO TESTAR SE ESTÁ FUNCIONANDO?
---------------------------------

  1. Salve qualquer arquivo Excel, Word ou PDF no Desktop
  2. Aguarde 30 segundos
  3. Abra o Telegram no celular
  4. Vá no grupo do bot
  5. Entre no tópico "Arquivos PC (Local)"
  6. Seu arquivo vai estar lá!


IMPORTANTE SABER
----------------

O script envia:
  - Arquivos NOVOS que você salvar
  - Arquivos MODIFICADOS recentemente (últimas 24 horas)
  - Apenas do Desktop e Documentos

O script NÃO envia:
  - Arquivos antigos (mais de 24 horas sem mexer)
  - Arquivos temporários do Excel (~$arquivo.xlsx)
  - O mesmo arquivo duas vezes (sem duplicatas!)


E SE EU REINICIAR O COMPUTADOR?

NÃO PRECISA FAZER NADA!

Quando você ligar o computador e fazer login, o script inicia sozinho 
automaticamente. Você nem vai perceber que ele está rodando.
